# dantebertuzzi.github.io

Personal site, laid out as a working paper: abstract, a figure, a table of
packages, research, methods and correspondence.

- **Figure 1** is real data: hydrological-year rainfall at INMET station 82983
  (Petrolina), from [meteo](https://github.com/dantebertuzzi/meteo), with a
  Sen–Theil trend computed at build time.
- **Table 1** shows each package's commits per week over the last 52 weeks.
- Four colour themes (auto, paper, night, caatinga), remembered per visitor.

Static `index.html` with inline CSS and SVG; the only script switches themes
and sorts the table. No trackers. The previous Perth.jl landing page lives in
[`perth/`](perth/).
