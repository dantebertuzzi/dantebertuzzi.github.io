Dante Bertuzzi

Statistician. I write Julia packages that make Brazilian public data reproducible — and I study the climate of the place I live.

Abstract

Public data in Brazil is rich and hard to reach: compressed DBC files, Latin-1 encodings, layouts that change between releases. My work absorbs that mess once, in open-source Julia packages, so the analysis can start at the question instead of at the file format. Ten packages so far cover health records, elections, crime statistics, the central bank, ocean biodiversity, data quality, document templating and project management. I also write reproducible research: my latest preprint estimates that a year as dry as 2012/13, once expected about every 38 years in Petrolina, now comes about every 12.

Keywords: statistics · Julia · public data · reproducibility · semi-arid

Methods

How I work, in four rules.

  1. 3.1Absorb the mess once

    DBC files, Latin-1, layouts that drift between years — handled inside the package, so nobody downstream has to.

  2. 3.2Check the null before trusting it

    Several classical election-forensics nulls do not hold for vote counts. The package measures the error rate it actually delivers on your data.

  3. 3.3Every number comes from code

    Papers are generated, not typed: figures, tables and the numbers in the prose all come out of the same reproducible run.

  4. 3.4Few dependencies, small surface

    Terminal heatmaps with no plotting library; API clients without HTTP.jl. Fast to load, easy to keep alive.
