bridge

One plan, two views — the chart and the board stay in sync.

multiplayer

Share a link, see everyone's cursor.

Start with share = true and Perth prints a link — and a QR code — for your local network. Anyone who opens it joins the same board or chart: every machine gets a labelled cursor with its name and address, a stable colour, and edits that appear live. Add an access key when the network is bigger than your team. Nothing ever crosses the internet.

features

Small package, real project management.

Real scheduling

Critical path, slack, dependency lag and SS/FF links, business-day calendars with holidays. Auto-schedule pushes successors when a task slips.

REPL-first

The browser and the REPL edit the same data, live. Script a whole plan, tweak a task from code, and mirror every save to a .perth.jl file — Pluto-style.

Baselines & S-curve

Snapshot the original plan and watch drift against it: baseline bars on the chart, planned vs. earned on the S-curve.

Flow metrics

Lead time, weekly throughput and work-in-progress age, computed from the board itself. An activity log answers "who changed this?".

Five languages

English, Português, Español, Français and 中文 — one click in settings, and the preference follows you between the two tools.

Installable & exportable

Both tools install as apps (PWA) and open offline. Export tasks as CSV, or the chart as PNG / PDF straight from the File menu.

new to julia?

Get Julia running in under a minute.

Perth is a Julia package, so you need Julia first. The official way is juliaup, a small version manager — it installs the current release, keeps it updated, and lets you switch versions later with one command. 

$ curl -fsSL https://install.julialang.org | sh

Open a new terminal (so your shell picks up the updated PATH), then check it worked:

$ julia --version
> winget install julia -s msstore

No winget? Grab the installer from julialang.org/install instead. Open a new terminal after installing, then check it worked:

> julia --version

juliaup also manages versions if you need them later — juliaup add release installs the latest, juliaup update keeps it current, and juliaup status shows what's installed. Once julia --version works, jump to quickstart below to add Perth.

quickstart

Three commands to a shared plan.

1 / install

Add the package

pkg> add Perth

One dependency. Optional extras — QR codes, business days, chart export — load only if you ask for them.

2 / run

Open the tools

julia> using Perth
julia> Perth.run()
julia> Perth.kanban()

The gantt and the board open in your browser. The REPL stays free — that's the point.

3 / share

Bring the team in

julia> Perth.kanban(
  share = true,
  key = "sesame")

Send the printed link (or point a phone at the QR code). Everyone's in — cursors and all.
